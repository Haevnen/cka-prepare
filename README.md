# k8s-labs

- A collection of small, hands-on Kubernetes labs designed to reproduce, investigate, and troubleshoot real-world cluster issues.

- Each lab explores a specific problem, from networking and scheduling to storage and workload failures, helping build practical Kubernetes knowledge through experimentation.

## Labs

- [Networking](./networking/) : How Pods and services communicate. Covers DNS, Services, ports, Ingress, and tracking traffic sources.

- [Scheduling](./scheduling/) : Where and when Pods run. Covers node selection, taints and tolerations, resource constraints, draining nodes, and spreading replicas across zones.

- [Storage](./storage/) : How applications keep and access data. Covers volumes, persistent volumes (PVs), claims (PVCs), and storage classes
- [Workloads](./workloads/) : How applications run in Kubernetes. Covers Pods, containers, deployments, images, and managing application processes
