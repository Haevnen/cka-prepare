# Deploy app to EKS cluster

## Steps to create an EKS cluster

- Step 1: Create EKS IAM Role

- Step 2: Create VPC for Worker Nodes

- Step 3: Create EKS cluster (Control Plan nodes) and Connect kubectl with EKS cluster

- Step 4: Create EC2 IAM Role for Node Group and Create Node Group and attach to EKS cluster

- Step 5: Configure auto-scaling and Deploy application to EKS cluster
